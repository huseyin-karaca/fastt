On the four corpora that are out of domain for the experts, <span class="nw">FASTT</span> has a significantly lower word error rate than the best single model (paired 5×2 cv F test, p < 0.05). It closes 32.4 %, 32.2 % and 29.0 % of the gap to the per-utterance oracle on AMI-SDM, Earnings-22 and People's Speech, and 10.5 % on VoxPopuli. On LibriSpeech, where one expert dominates, it ties with the best single model (p = 0.737). Because it chooses before any decoder runs, it avoids 86 % of the time of a decode-all ensemble at beam width 5.
